# Coleta de Requisitos — PRIORIS

Esta pasta contém a documentação de requisitos da V1 do Prioris.

## Arquivos

- `01_Requisitos_Prioris.md` — tema, escopo, ator, RFs, RNFs e regras de negócio.
- `02_Historias_Usuario_Prioris.md` — 12 histórias de usuário com critérios de aceitação.
- `03_Casos_Uso_Prioris.md` — 10 casos de uso textuais.
- `04_Diagrama_Casos_Uso_Prioris.md` — diagrama visual em Mermaid.

## Observação

A documentação reflete a V1 atualmente implementada. Funcionalidades planejadas para versões futuras não são tratadas como requisitos concluídos da V1.
